# Mom's Map

Приложение для мам: карта детской инфраструктуры города, мероприятия и знакомства с мамами рядом.

## Что уже есть (MVP)

- **Карта** (OpenStreetMap + Leaflet) с метками: детские площадки, туалеты и пеленальные, пандусы и лифты, препятствия (перекопано, плохое покрытие), кафе с детской комнатой, удобные магазины.
- **Фильтры** по категориям и по возрасту ребёнка (до 1 года, 1–3, 3–5).
- **Свои метки**: кнопка «＋», нажать на карту, выбрать тип и заполнить.
- **Отзывы и оценки** к местам.
- **Мероприятия**: ставятся на карту и собраны во вкладке «Мероприятия» по дате.
- **Профиль**: интересы, возраст ребёнка, статус («рада прогуляться», «хочу творить», «хочу пообщаться») и необязательный показ себя на карте.

Данные пока хранятся в браузере (`localStorage`), а метки, отзывы и мамы на карте — демо-данные.

## Запуск

```bash
cd app
npm install
npm run dev      # разработка
npm run build    # сборка
npm run lint
```
