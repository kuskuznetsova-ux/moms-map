# Mom's Map

Приложение для мам: карта детской инфраструктуры города, мероприятия и знакомства с мамами рядом.

## Что уже есть (тестовая версия)

- **Карта** (OpenStreetMap + Leaflet) с метками: детские площадки, туалеты и пеленальные, пандусы и лифты, препятствия, кафе с детской комнатой, магазины и мероприятия.
- **Фильтры** по категориям и возрасту ребёнка (до 1 года, 1–3, 3–5).
- **Свои метки**: «＋», затем «📍 Я здесь» или нажать на карту.
- **Отзывы и оценки**, **мероприятия** (на карте и списком по дате).
- **Вход по имени или псевдониму** с согласием. Email, телефон, данные о детях и местоположение пользователя не собираются.
- **Жалобы** на метки и удаление своих данных.
- **Общая карта** через Supabase. Без его настройки приложение работает локально.

Показ мам рядом и личные сообщения временно отключены, пока нет проверки пользователей. Подробнее: [docs/SAFETY.md](docs/SAFETY.md). Для тестировщицы: [docs/TESTER.md](docs/TESTER.md).

## Запуск

```bash
cd app
npm install
npm run dev      # разработка
npm run build    # сборка
npm run lint
```

## Общая база (Supabase)

1. Создайте проект на supabase.com и включите Authentication → Sign In / Providers → **Anonymous Sign-Ins**.
2. Выполните [supabase/schema.sql](supabase/schema.sql) в SQL Editor.
3. Локально: скопируйте `app/.env.example` в `app/.env.local` и заполните адрес проекта и `anon`-ключ.
4. Для GitHub Pages: Settings → Secrets and variables → Actions → **Variables**, добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

Supabase может быть недоступен у некоторых российских операторов, проверьте до запуска. Слой данных (`app/src/api.ts`) отделён от интерфейса, поэтому сервер можно заменить.
